# 🎨 Aircanvas


The project tracks your index finger using **MediaPipe** and **OpenCV**, turning your hand movement into a digital drawing.

### 🚀 Current Features

* ✋ Real-time hand tracking
* ☝️ Index-finger air drawing
* 🎨 Persistent virtual canvas
* 🧹 Clear canvas with `C`
* ❌ Exit with `Q`

### 🛠️ Tech Stack

* Python
* OpenCV
* MediaPipe
* NumPy

### 🔮 Planned Features

* ⏱️ 20-second drawing challenges
* 🧠 AI-based drawing recognition
* 📊 Recognition confidence and analysis
* 🔄 Automatic next drawing if AI can't recognize the sketch
